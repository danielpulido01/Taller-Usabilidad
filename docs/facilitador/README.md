**Antes del taller**

- [ ] `npm run test:v2` da 3 aprobadas y `npm run test:v1` da 3 fallidas.
- [ ] Las URL de GitHub Pages de v1 y v2 abren (se publican con cada push a `main`).
- [ ] Si se usan mapas de calor en Maze, la variable de repositorio `MAZE_SNIPPET` está configurada (ver
      [estudio-maze.md](estudio-maze.md#3-preparación-técnica)).
- [ ] El enlace al archivo de Figma para el rediseño de la Parte 4 está listo para compartir.
